Chrome extension

Use on P2P, explorers, Telegram

Agents highlight a wallet on binance.com/p2p, Etherscan, or Telegram Web and trace without leaving the tab. Load it unpacked in Chrome. Pin the API base to this desk.

  1. Download the extension zip from this page.
  2. Unzip. Chrome → Extensions → Developer mode → Load unpacked → select the extension folder.
  3. Set API base to this desk’s origin, then Trace.
